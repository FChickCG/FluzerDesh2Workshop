# Fluzer Desh 2 — гайд по созданию модов

Моды пишутся на **Lua** и живут в репозитории [FluzerDesh2Workshop](https://github.com/FChickCG/FluzerDesh2Workshop).
Игра сама скачивает их во вкладке «Мастерская», а в мультиплеере моды хоста автоматически докачиваются всем игрокам на сервере.

---

## 1. Структура репозитория

```
FluzerDesh2Workshop/
├── index.json          ← каталог всех модов (обязателен)
└── mods/
    ├── mymod.lua       ← код мода
    └── другоймод.lua
```

## 2. Регистрация мода в index.json

Добавьте запись в массив `mods`:

```json
{
  "mods": [
    {
      "id": "mymod",
      "title": "Мой Мод",
      "author": "ВашНик",
      "description": "Меняет звук прыжка",
      "preview": "https://сайт.ру/превью.png",
      "luaUrl": "",
      "sizeKb": 1
    }
  ]
}
```

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | Имя файла мода без `.lua`. Латиница/цифры, без пробелов |
| `title` | нет | Отображаемое название (иначе покажется id) |
| `author` | нет | Ник автора — доступен моду через `api.get_author()` |
| `description` | нет | Описание |
| `preview` | нет | Прямая ссылка на картинку-превью (png/jpg) для списка |
| `luaUrl` | нет | Пусто = код берётся из `mods/<id>.lua`. Или полный прямой URL на .lua где угодно |
| `sizeKb` | нет | Размер мода в килобайтах (для отображения; иначе прочерк) |

**Важно:** имя записи `id` должно совпадать с именем файла `mods/<id>.lua`.

## 3. Код мода

Точка входа — функция `init()`, она вызывается при установке и включении мода:

```lua
function init()
  api.log("Мод загружен!")
end
```

### API (глобальный объект `api`)

**Информация:**

| Функция | Возвращает | Описание |
|---|---|---|
| `api.get_mod_id()` | string | id мода |
| `api.get_author()` | string | ник автора из index.json |
| `api.get_title()` | string | название мода |
| `api.get_description()` | string | описание мода |
| `api.get_player_nickname()` | string | ник текущего игрока |
| `api.get_coins()` | число | баланс монет игрока |
| `api.is_online()` | true/false | находимся ли в онлайн-комнате |

**Звуки** (все — прямые ссылки на `.mp3`/`.wav`):

| Функция | Описание |
|---|---|
| `api.set_jump_sound(url)` | звук прыжка |
| `api.set_damage_sound(url)` | звук получения урона |
| `api.set_death_sound(url)` | звук смерти |
| `api.set_finish_sound(url)` | звук при пересечении финиша |
| `api.set_level_music(url)` | музыка уровня целиком (зациклена) |

**Физика игрока:**

| Функция | Стандарт | Описание |
|---|---|---|
| `api.set_jump_force(n)` | ~12 | сила прыжка |
| `api.set_run_speed(n)` | ~7 | скорость бега |
| `api.set_gravity(n)` | ~5 | гравитация (меньше = «лунные» прыжки) |
| `api.set_max_hp(n)` | 100 | максимальное здоровье |

**UI и устройство:**

| Функция | Описание |
|---|---|
| `api.show_message(text, seconds)` | всплывающее сообщение на экране уровня |
| `api.vibrate()` | вибрация устройства (на ПК ничего) |
| `api.open_url(url)` | открыть ссылку в браузере |
| `api.log(message)` | сообщение в консоль игры |

### Пример 1 — замена звуков

```lua
function init()
  api.log("Загружаю звуки от " .. api.get_author())
  api.set_jump_sound("https://example.org/sounds/boing.mp3")
  api.set_damage_sound("https://example.org/sounds/ouch.wav")
end
```

После установки звук прыжка и урона меняется сразу, без перезапуска.
Выключение мода кнопкой возвращает стандартные звуки.

### Пример 2 — «лунная гравитация»

```lua
function init()
  api.set_gravity(2)        -- медленное падение
  api.set_jump_force(14)    -- чуть выше прыжок
  api.show_message("Лунная гравитация активна!", 4)
  api.vibrate()
end
```

### Пример 3 — комплексный мод

```lua
function init()
  if api.is_online() then
    api.show_message("Онлайн-режим: мод работает и у других!", 3)
  end

  api.set_level_music("https://example.org/music/epic.mp3")
  api.set_death_sound("https://example.org/sounds/wilhelm.wav")
  api.set_finish_sound("https://example.org/sounds/victory.mp3")

  api.log("Игрок: " .. api.get_player_nickname() .. ", монет: " .. api.get_coins())
end
```

## 4. Требования к ссылкам на звуки

- Ссылка должна быть **прямой** — вести именно на файл, а не на страницу сайта.
  Если в браузере по ссылке файл скачивается/играет — годится.
- Форматы: **`.mp3`** или **`.wav`** (работают на Android). `.ogg` работает только в редакторе Unity — не используйте.
- Хостинги с защитой от хотлинков могут отдавать ошибку 403 — проверяйте ссылку.
- Удобные варианты: GitHub (raw-ссылки), Google Drive (прямая ссылка скачивания), свой сервер.

## 5. Ограничения песочницы

Моды исполняются в изолированной среде MoonSharp (SoftSandbox):
- нет доступа к файлам, сети напрямую, процессам ОС;
- доступны только возможности API выше и стандартная Lua-библиотека (`math`, `string`, `table`).

Так игроки могут безопасно ставить любые моды из мастерской.

## 6. Как опубликовать

1. Форкните/склонируйте репозиторий `FChickCG/FluzerDesh2Workshop`.
2. Создайте `mods/<ваш_id>.lua`.
3. Добавьте запись в `index.json` с тем же `id`.
4. Закоммитьте и запушьте в ветку `main`.
5. В игре откройте «Мастерскую», нажмите «Обновить» — мод появится в списке. Жмите «Скачать».

Готово! Игроки, зашедшие на ваш сервер, получат мод автоматически.
